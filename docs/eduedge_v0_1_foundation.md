# EduEdge V0.1 foundation

This slice introduces the application and platform boundary, not the full school-management feature set.

Delivered:

- Frappe app metadata and dependency contract.
- EduEdge product identity and feature-key registry.
- standalone/remote CoreEdge client abstraction.
- sanitized platform configuration.
- access decision caching and fail-open/fail-closed handling.
- School Branch/Campus master.
- EduEdge Settings.
- branch-context APIs.
- setup-readiness API.
- EdgeSuite UI Setup Center.
- roles and workspace.
- static repository and configuration tests.

Deferred:

- branch fields on Frappe Education transactions;
- admissions workflow improvements;
- fees and accounting;
- CBT and offline-resilient answer sync;
- Student Pickup and School Bus;
- dashboards and EdgeFinder publication.
